# Bible OnAir — 배포

교회 예배에서 성경 구절을 스크린에 송출하는 Windows 프로그램, **Bible OnAir** 의 설치 파일을 내려받는 곳입니다.

## 내려받기

**[최신 버전 내려받기](https://github.com/dode777/Bible-OnAir-Releases/releases/latest)**

위 링크에서 `Bible-OnAir-Setup-<버전>.exe` 를 받아 실행하시면 됩니다.
관리자 권한은 필요 없고, 바탕화면과 시작 메뉴에 바로가기가 만들어집니다.

한 번 설치한 뒤로는 프로그램이 새 버전을 스스로 확인하므로, 이 페이지를 다시 찾아오실 필요는 없습니다.

### 설치할 때 "Windows의 PC 보호" 창이 뜨면

파란 화면이 나오면 **`추가 정보`** → **`실행`** 을 누르시면 됩니다.
프로그램에 문제가 있어서가 아니라, 아직 코드 서명 인증서를 붙이지 않아 나오는 안내입니다.

## 이 저장소에 대해

배포 전용입니다. 설치 파일과 업데이트 정보(`latest.yml`)만 올라가며, 프로그램 소스 코드는 들어 있지 않습니다.

## 본문

저작권이 소멸된 **「성경전서 개역한글판」(1961)** 을 기본 본문으로 씁니다.
개역개정은 대한성서공회의 저작권물이라 사용 허락을 확보한 뒤에 제공할 예정입니다.
