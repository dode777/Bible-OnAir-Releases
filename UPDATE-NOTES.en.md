## 2.0.0
### Google Login and Account Features Added

- Added the Google login feature.
  You can still use all the features of the previous version without logging in.
- By logging in, you can use various additional features,
  such as syncing favorites and settings across multiple PCs.
- Moving forward, you can access various features in the Account → Lab menu after logging in.
  In the current version, you can try out the verse search feature in the Lab.
  (Turn on the feature in the Lab and click the search icon or press Ctrl + F.)

## 1.2.2
### Organized Settings Window and Long Verse Display

- Consolidated screen and broadcast subtitle settings into the Settings window (⚙).
- Long verses are now displayed across multiple screens instead of reducing text size.
- Broadcast subtitles can now be displayed at the top of the screen as well.
- Matched the line breaks of the preview screen with the output screen.
- Notifications are now displayed in a single location within the header.
- Created a brand new app icon and installation screen.

## 1.2.1
### Refined Issues Identified During 1.2.0 Usage

- Displays the valid range if an incorrect port number is entered.
- Fixed an issue where the checklist in the broadcast subtitle guide
  mistakenly displayed screen output as subtitle output.
- Release notes can now be viewed on the update installation preparation screen as well.
- Cleaned up notification and menu texts to make them more concise.

## 1.2.0
### Broadcast Subtitle Feature Added

- You can now overlay Bible verse subtitles with transparent backgrounds on live screens. (vMix·OBS)
- In the output panel, you can choose between "Screen" and "Broadcast Subtitles" for output.
- Turning off the output (Q) closes the output window,
  and turning it back on (O) resumes from the verse you were viewing.
- The output screen now displays in full screen without the taskbar.
- Moved favorites to the tab next to the verse selection.

## 1.1.1

- Fixed an issue where the output screen flickered when changing font size.
- Improved the update guide UI, which can be checked by clicking the version button.

## 1.1.0

- Modified how the settings tab operates.
