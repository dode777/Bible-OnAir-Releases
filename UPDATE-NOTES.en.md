## 1.1.1
### Improved User Experience

- Fixed an issue where the output screen flickered when changing the font size.
- Improved the update notice UI that appears when clicking the version button.

## 1.1.0
### Addressed User Requests & Feedback

- Modified how the Settings tab operates.
- Fixed a bug related to verse selection.
- Refined the output mode (Two-Three Verses) to be more natural. The number of displayed verses now adjusts more smoothly based on the font size.
- Improved the UI responsiveness to window size, preventing the preview window from displaying too small.
- Added more font size options. You can now choose from a total of 5 levels, ranging from 'Small' to 'Very Large'.

### Bible OnAir has been released.
